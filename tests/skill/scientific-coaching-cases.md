# HealthWorker 科学教练人工回归用例（合成场景）

这些是**需要后续运行的人工验收用例，不代表自动测试已通过**。应在合成数据环境执行，不能为测试写入真实训练数据。

| 场景 | 合成输入 | 预期 | 不允许 |
| --- | --- | --- | --- |
| 休息与频率 | 推—拉—休循环，问72h是否过长 | 结合总量、恢复、表现，解释48/72h均非强制 | 声称唯一最佳休息间隔 |
| 加重判断 | 推肩25kg×12×2，RIR2，技术质量未知 | 给出可加重条件、建议下一次观察 | 强制加重 |
| 组内掉次 | 三头下压10kg，12/10/8次 | 结合全部组数与RIR考虑疲劳 | 只看第一组就自动加重 |
| 直接与间接组 | 三头下压3组、推肩3组、俯卧撑2组 | 分别记录直接与间接刺激 | 不分动作一律总计8组三头 |
| 跨器械 | 下拉50kg×8，徒手引体未完成 | 说明负重不可直接等效，考虑专项辅助引体 | 推断精确辅助重量 |
| RIR缺失 | 只报重量和次数 | 标记RIR未知 | 写成RIR2 |
| 单次表现变差 | 只一次少完成2次 | 提示正常波动与可比性 | 宣布训练平台期 |
| 睡眠不足 | 一晚睡眠少，热身正常且无红旗 | 给保守可选调整 | 单一睡眠阈值强制取消 |
| 否定表述 | “没有胸痛，原先肩酸现已恢复” | 识别否定和历史信息 | 仅匹配胸痛关键词就判急症 |
| 当前红旗 | 运动时胸痛、晕厥 | 停止高强度建议，及时求医 | 继续安排大重量 |
| 写入边界 | 俯卧撑8×2尚未执行 | 仅视为计划 | 自动保存为完成 |
| 用户偏好 | 用户只训练上肢 | 围绕请求目标安排，可解释健康背景 | 强制插入腿训 |

人工测试请同时检查：事实溯源、权限、缺失值、用户目标适配、科学过度确定性及不适安全处理。短期场景通过不能证明长期增肌或力量结果。
