# M3 独立代码 review 与修复证据

同步主 agent 交接的独立代码 review，核对实际测试，不是 GUI 全通过声明。对应设计 1.3 §5、§3.6、A05–A08、A14、A16–A17。

## Review 修复

有氧某组距离全为 null 时，SQLite `sum(nullable predicate)` 可返回 NULL，导致 paceSampleCount 不满足非负整数 schema，接口曾返回 500。`src/worker/stats.ts` 已改为 CASE/ELSE 0 计数；有效配速样本为 0，速度/配速仍 null，不把缺失变零成绩。

`tests/integration/stats.test.ts` 的首项回归实际验证：全 null 距离组单独查询及与另一 category 同时查询均返回 200；组有效样本为 0，速率为 null。另有 >10000 明细返回 422、completed 父下旧未完成子记录排除、容量倍率/排除原因、缺失重量、按辅助重量分组、320 秒/km 总量比、elapsed/moving 分离、缺失/零距离、游泳单位、周/月裁剪桶、混合训练去重、localDate/DST、空状态与 Agent 同源结果等测试。

## 实现与实测

summary/strength/cardio 复用后端统计；React/Recharts 总览/趋势只展示，附范围、质量计数与可访问明细表。`tests/unit/web-stats.test.ts` 覆盖零与缺失区别、范围与排除信息、无假图表的空状态。统计最多 10000 条读取明细，超限要求缩小范围，不截断。

本轮 12 个 stats D1 集成与 2 个 web-stats 测试纳入全仓 33 TS 单元/46 D1 集成并通过；typecheck/lint/build 通过。Stats 路由块 409.54 kB（gzip 120.39 kB），主 JS 486.05 kB（gzip 153.53 kB）；未测 2000 训练/100000 组参考规模 p95。
