## 迭代中发现及处理

- Drizzle Kit 0.31.10 对绝对 out 路径会拼接 `./` 导致 ENOENT；改用指向临时目录的相对 out，实际干净生成通过，未在仓库运行生成覆盖 SQL。
- workerd 不支持浏览器 redirect:error；HTTP 测试适配层仅将其转换为 manual 并拒绝 3xx，以及模拟浏览器 Origin。没有添加/修正 Content-Type，客户端自身真实 headers 是被测对象；不是浏览器验收。
- 主题测试初始合成 settings 漏 id 字段，被共享 schema 正确拒绝；补齐 fixture。Mantine 弹层使用 env=test；没有 mock 主题 hook/Settings/API 客户端。
- 最初 200 组完整 jsdom 表单渲染过慢，主动终止该测试任务（未重启 dev server），改为足够超过 512 KiB 的 50 组合法备注，测试超时调整为 30 秒；最终全套通过。最大 300 组仍由纯逻辑载荷测试及 workerd 集成覆盖。
