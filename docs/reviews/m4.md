# M4 独立代码 review 与修复证据

同步独立 review 交接并核对当前测试，不是本收尾重新执行独立 review 或 GUI。对应设计 1.3 §§6、8–9、11，A13、A15、A18。

## 恢复与设置/导出

- Review 发现恢复仅检查结构时，历史计量快照下非法组可能被接受。`src/shared/backup.ts` 与 `scripts/restore-local.py` 已验证快照计量语义与完成父子约束。
- `tests/unit/restore.test.ts` 实际启动 Python 脚本，以合成 JSON 创建新本地 SQLite；验证 ID/version/备注/历史名称/引用、外键以及 100 kg ×5×3=1500 kg·次。拒绝覆盖、悬空引用、与快照不符的次数/时长/辅助重量、完成父下未完成组、空组/空完成父、--remote，并确认失败不留下目标文件。
- 该演练不是恢复到远端 D1，也不是全部统计指标生产恢复认证。仅新本地 SQLite；JSON 是恢复格式，CSV 是查阅格式。
- `tests/integration/m4.test.ts` 4 项实际通过：GET settings 无持久化副作用、虚拟 version1/UTC、错误首次版本不初始化、并发 PATCH 仅一方成功、固定 locale/公制约束；JSON 含草稿/归档/备注且无幂等技术凭证，CSV 公式转义；Agent 不开放管理面；保守字节预算超限 413 不截断。150000 行阈值由实现约束，但本轮独立超限 fixture 实测的是字节预算，不冒称单独测试了 150001 行。
- `tests/unit/web-export.test.ts` 验证 Blob 原始附件与 CSV dataset、拒绝 HTML/附件不符；不是浏览器下载 GUI 验收。

## Skill review

CLI 对 cardio nested category/durationBasis 曾误把缺失/null 当未筛选。现 groups/records 必须有合法非 null 维度；顶层筛选字段必须存在但可 null。`tests/skill/test_healthworker.py` 的三项 cardio dimension 回归验证缺失/null/非法拒绝和有效组合通过。

27 个 Python unittest 实际重跑通过（含真实本地标准库 HTTP transport 的合成 smoke）。覆盖仅 GET 白名单、metadata 版本/能力预检、开发模式不发送继承凭证、分页上限与恢复游标、失败不输出部分结果、备注显式读取、错误脱敏、HTML/所有重定向拒绝、TLS 不重试、网络/429/5xx 有界重试。20 秒是 socket 操作超时，不是整体 wall-clock 上限；初次后最多 3 retry，默认 1/2/4 秒，Retry-After 0–30 秒，响应体 16 MiB。没有外部服务或真实 Service Token 验收。
