## 填写纪律

- 数字必须来自真实输出，禁止从 README 或上一轮报告复制。
- 每条 P0/P1 必须能复现；不能复现的降级为 `L3 待验证假设`，单列一节，不计入必修项。
- "已核实无问题"一节同样重要：它把排除结论固定下来，避免下一轮和修复方重复排查。
- 报告中不出现真实凭证、audience、邮箱、域名或训练数据；需要引用私有配置时只写文件路径。
- 临时文件、临时测试、临时目录必须已删除，并在报告里写明重建方式。
